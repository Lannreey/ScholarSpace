ScholarSpace

A Student Portfolio and Academic Management Website

ScholarSpace is a responsive, multi-page website developed as a practical term project for COS 106: Introduction to Web Technologies.

Project Overview

ScholarSpace provides students with a platform to showcase their academic profiles, display projects, organise academic tasks and communicate through a contact form.

Website Pages

* Home: Introduction and website overview.
* About: Student profile and background.
* Projects: Showcase of academic and personal projects.
* Academic Planner: Organising and managing academic tasks.
* Contact: Contact form for enquiries.

Technologies Used

* HTML5
* CSS3
* JavaScript

Features

* Responsive website design.
* Multi-page navigation.
* Academic task management.
* Contact form validation.
* Images and multimedia integration.
